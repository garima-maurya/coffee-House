# ☕ Coffee House Website

A simple and elegant coffee shop website built using **HTML5 and CSS3**. This project was created to practice frontend fundamentals and build a complete multi-section website from scratch.

## 🌐 Links

- **Repository:** https://github.com/garima-maurya/coffee-House
- **Live Demo:** https://garima-maurya.github.io/coffee-House/

## ✨ Features

- Home / Hero section
- About Our Coffee section
- Cozy Space image gallery
- Coffee menu with 10 product cards
- Product name, description, price and Order Now button
- Contact section
- Sticky navigation bar
- Navigation between website sections

## 🛠️ Technologies Used

- HTML5
- CSS3

### CSS Concepts Practiced

- Box Model
- Margin & Padding
- Relative, Absolute & Sticky Positioning
- Z-index
- Border Radius
- Box Shadow
- Background Images
- Reusable Classes
- Text Styling
- Smooth Scrolling

## 📋 Website Sections

**Home:** Coffee House introduction, logo, tagline and Explore Menu button.

**About:** Information about the coffee house and a Cozy Space gallery.

**Menu:** Different coffee products with images, descriptions, prices and Order Now buttons.

**Contact:** Location, phone number, email and opening hours.
